# Folia 26.3 同步与验证

本次更新在 `26.3.x` 分支完成，基于 Folia `ver/26.3.x` 的
`597e41371802648e0455fc1571192ee1c83fca2b`，其 Paper 引用为
`c927bd34ab4b544cc125367ea62c7ea2f1a2196d`。

Minecraft、API 和项目版本均更新至 26.3；构建工具与上游对齐为
Gradle 9.8.1、paperweight 2.0.0-beta.24，使用 JDK 25。

## 兼容调整

- 重定位现有 Minecraft/Paper 补丁，保留上游新的移动校验和路径调试编码。
- AFK 处理适配实体移除列表、载具坐标 API 以及新的挥手数据包；自身挥手继续直接发送。
- Lithium 保留 26.3 的新挥手状态和流体标签实现，删除现有补丁中已不适用的旧逻辑。
- 构建脚本补丁适配上游 Leafpile 模块拆分及 Spark 更新。

未新增、删除或重命名任何 `.patch` 文件。活动补丁仍为 13 个 Minecraft
功能补丁、2 个 Paper 功能补丁、2 个构建脚本补丁；包含历史归档在内的
全部 24 个 patch 路径与升级前一致。

## 端到端验证

实际运行生成的 Paperclip JAR，使用隔离世界、两个真实 TCP 协议客户端、
Folia 调度器和临时测试插件。检查包括：

- 品牌、26.3 版本、配置加载和 `/afknetstats` 注册及执行。
- 压缩与非压缩 TCP 数据包、区块批次、登录、传送确认和保持连接。
- AFK 后抑制方块、声音及 26.3 挥手数据包，聊天和持久 UI 继续发送；
  玩家恢复活动后重新发送区块，进入/退出提示及统计正常。
- 异步路径创建、完成回调及实际移动，未完成路径的 `sameAs` 防护，空目标访问。
- 村民持续运行并获取工作站 POI，DAB 优先级保持有效范围。
- Kaiiju 将超限实体移除到配置上限；关闭限流后保留全部测试实体。
- 活塞红石伸展、无方块实体的活塞幽灵方块可重新放置、普通落沙落地。
- 清空末地目标区域后投入一个落沙，末地平台生成，最终得到两份沙子。
- 空事件监听器及注册监听器的事件执行行为。
- 相隔超过 2,000 格的区域间传送、区域所有权检查、末地往返。
- 正常保存、退出、重新启动后恢复世界方块，并重新登录、正常发送数据包。
- 关闭 DAB、异步寻路、Kaiiju、网络优化、Lithium、POI、AFK 优化后，
  同步寻路、实体、POI、红石及网络回退路径正常。

完成的端到端运行均检查服务端日志中没有 ERROR、异常堆栈或测试失败，
并检查进程正常退出。幽灵方块测试会触发该修复原有的预期 WARN 提示。

本工作区的临时测试插件、协议客户端及运行脚本保存在 `build/e2e/harness/`，
结果和日志保存在 `build/e2e/`；它们不参与服务端打包，也没有形成新 patch。

云环境要求通过 HTTP 代理访问外网，但上游部分 Mojang 服务请求显式使用
`Proxy.NO_PROXY`。测试通过本机转发访问官方 HTTPS 服务，只为测试 JVM
设置 `minecraft.api.discovery.host`，没有修改服务端代码、伪造公钥或关闭校验。
调整网络访问后重新实际运行了服务端测试，日志没有连接异常。

测试使用仅绑定本机地址的离线玩家，不覆盖正版账户鉴权和第三方插件兼容性；
这些结果也不代表对所有可能游戏场景的穷尽验证。
